# 品牌应用系统

## 主 Skill 路由适配

本 ref 只提供品牌触点物料的产物规则。被 `creative-design` 路由调用时，**工具协议、澄清轮次、核心资产记录、张数策略、prompt 总规则、文字与事实纪律、质检基准一律以主 `SKILL.md` 为准**；本文件只补充品牌资产继承协议、物料版式骨架、触点场景规则、跨物料一致性锚定与品牌合规门禁。

**通用规则不在本文件复述**（中文/英文双引号框定、禁占位符、平台名禁入 prompt、单次调用 n=1、工具参数映射），一律以主 `SKILL.md` 为准；本文件与主 SKILL 冲突时以主 SKILL 为准。

## 概述

品牌应用物料的共同特征是：**画面里必须出现并可识别品牌资产**（Logo、IP、包装、品牌色、字体规范、图形母题或既有主 KV）。它的价值不在单张图的视觉冲击，而在**同一套品牌识别在多个触点上的复现**——换画幅、换尺寸、换场景，品牌识别不漂移。

核心原则：先锁品牌识别，再谈版式美感。品牌资产的继承优先级高于单张图的构图创意。

### 与其他 ref 的分工边界

| 情形 | 走哪个 ref | 本 ref 的角色 |
|---|---|---|
| 已有品牌资产，做活动 KV、门店、展会、宣传册 | **本 ref** | 主体 |
| 已有品牌资产，但要发到小红书/抖音/公众号 | 本 ref 出主 KV → 对应 media ref 出平台版 | 本 ref 提供核心资产，画幅与信息密度向 media ref 看齐 |
| 有品牌资产，但核心是商品主图/详情页转化 | ecommerce-design | 本 ref 只出品牌底图/主 KV 作参考 |
| 有品牌资产，但要做盒子/瓶身/礼盒本体 | brand-packaging-system | 本 ref 只做包装之外的触点 |
| 无品牌资产，纯内容传播或泛干货分享 | 对应 media ref | 不进入本 ref |
| 用户要"完整 VI / 品牌全案" | 先澄清交付范围，不默认按本 ref 一次做全 | 本 ref 承接已明确清单中的触点物料 |

## 使用场景

### 何时触发

- 用户提供了 Logo、品牌色、IP、包装图或已有主 KV，要求"用它做一套……"。
- 用户点名具体品牌触点物料：活动海报、传播封面、内容卡片、宣传册、折页、落地页、展会物料、易拉宝、门店陈列、贴纸、周边。
- 用户要求"品牌延展""品牌物料""触点应用""KV 延展""同一套视觉做多个场景"。
- 上下游接力：上游 ref（logo / ip / packaging）已产出核心资产，本 ref 承接做下游触点。

### 何时不触发

- 无任何品牌资产继承，核心是平台点击率、平台调性或商品转化（走 media ref / ecommerce-design）。
- 物料的"物理结构"是核心（盒型、刀模、瓶型）——走 brand-packaging-system。
- 纯图形 Logo 设计、字标设计、Logo 规范页——走 brand-logo-system。
- 纯角色设定、三视图、表情包——走 brand-ip-character-system。
- 平面设计稿以外的展示背景、样机与空间效果，只在目标是 mockup 或空间展示时描述。

| 用户点名 | 优先产物 |

| 宣传册 / 折页 | 多页跨页系统（封面 + 内页节奏 + 封底） |
| 落地页 / 长页 | 纵向分区结构，首屏钩子 + 逐屏信息推进 + 收口 |
| 展会物料 | 远距可读的背板 + 近距可读的指引/资料 + 打卡装置三层 |
| 易拉宝 | 竖版 + 远距主标题 + 中距卖点 + 近距 CTA |
| 门店 / 陈列 | 门头识别 + 墙面/展柜叙事 + 收银与物料统一 |
| 贴纸 / 周边 | 小尺寸可识别，图形母题优先，文字极简 |

## 核心流程

### Step 1：品牌资产盘点与核心资产锁定

先列清单再动手。缺哪一项就用合理默认值承接并记入内部计划，只有缺失会影响核心资产引用时才澄清。

1. **图形资产**：主 Logo（横版/竖版/单色版）、辅助图形、图形母题、品牌 IP 形象。
2. **色彩资产**：主色、辅色、点缀色、中性色阶、各色使用比例。
3. **字体资产**：主字体气质、辅助字体气质、字重层级习惯。
4. **既有物料**：是否已有主 KV、包装图、上一版物料（存在即为当前核心资产）。
5. **事实信息**：品牌名、中英文名、Slogan、活动名、日期、地点、联系方式、监管或版权声明。

- 用户上传的 Logo、品牌图、产品图、包装图、主 KV 默认是**当前核心资产**，除非用户明确说"仅参考风格"。
- 品牌资产齐备且有 Logo/IP/主 KV → 全部下游物料走 `image_edit` 引用核心资产。
- 品牌资产缺失到无法建立识别（既无 Logo 也无品牌色也无包装）→ 停在主 SKILL 通用流程或先做 Logo，不在本 ref 里凭空造品牌识别。
- 锁定项要逐条写进内部计划，延展时按锁定项检查，不临场重述。

### Step 2：物料组合规划与张数分配

张数以主 `SKILL.md` 策略为准，本 ref 的分配原则：
- **优先出主 KV 母版**：只要交付物超过 2 张且需要保持一致，第一张必须是可延展的主视觉母版，后续全部由它派生。
- **按物理尺寸分层**：远距识别的物料（背板、门头、易拉宝）先做，因为它决定品牌识别的最小可读尺寸；中距（海报、展板）与近距（卡片、贴纸、周边）随后。
- **成套物料的差异必须真实**：不同物料之间在画幅、场景、观看距离、信息密度上天然有差异，不允许出现"同一画面换比例"的伪系列。
- **交付范围不清时先确认清单**：用户说"做一套品牌物料"而未列清单时，按主 SKILL 澄清规则只问 1 个最关键问题（交付清单与张数），不要默认扩成全案。

### Step 3：版式骨架推演

遵循三层推演：**载体骨架 → 场景语义 → 实例填充**。

- **载体骨架**：物料的物理分区、阅读顺序、品牌识别落点、主信息层级。品牌识别在骨架阶段就要定位，不留到填充阶段临时找地方。
- **场景语义**：真实使用场景中合理存在的物件、环境、光影、观看距离与材料质感。落地页要考虑滚动，门店要考虑人流方向，展会要考虑展位动线。
- **实例填充**：把每个可见元素、文字、图形、材质、光影写成可直接生成的具体内容；文字逐字写出。

品牌应用的骨架统一遵守：**品牌识别固定位**（主 KV 主标位 / 海报落款位 / 门店门头位 / 背板左上或中上位 / 卡片角标位），同一系列内该位置不漂移。

### Step 4：一致性锚定

两层锚定，与主 SKILL「参考图选择协议」配合使用：
- **品牌层锚点（跨全部物料统一）**：Logo 版本与位置、主辅色比例、字体气质、图形母题、材质与工艺倾向。品牌层锚点由主 KV 母版（第一张）锁定。
- **物料层锚点（同物料家族内统一）**：栅格、文字容器样式、图文比例、信息密度、装饰语言。每个物料家族内部独立锁定，但必须继承品牌层锚点。

锚定执行：
- 品牌层锚点由主 KV 的本地文件承担，跨物料家族只继承品牌层，不强行继承其他物料的版式。
- 同一物料家族内（如 4 张内容卡片）的后续图，参考图用**该家族上一张**（物料层锚点）+ 主 KV（品牌层锚点），prompt 中分别写明两张图的作用。
- **参考图目的是保持品牌识别一致，不是保持画面构图一致**。不要因为"要一致"就把所有物料做成同一个画面。

### Step 5：品牌合规与事实审查

- 品牌名、中英文名、Slogan、活动名、日期、地点、联系方式、版权与监管声明，只能来自用户提供或已确认资产；未提供时不编造，改用非具体表达或从画面移除。
- 禁止使用 `XX`、`某某`、`标题文案`、`待补充文字`、`相关说明`、`占位符` 等让模型自由补字的表达。
- 不得使用第三方品牌、影视作品、受保护 IP 或在世艺术家姓名作为风格锚点；风格一律用通用视觉语言描述。
- Logo 在画面中不得被裁切、拉伸变形、加描边、加投影、加渐变、加外发光或与高对比背景直接相撞；必要时使用品牌色块或留白区承载。
- 门店、展会、易拉宝等户外物料要考虑**远距可读性**：主标题在预期观看距离下必须可读，正文小字不是这些物料的载体。
- 涉及健康、功效、收益、环保、认证、对比承诺的表述，必须由用户提供或改为中性表达。

### Step 6：工具调用与串联

- 工具字段、渠道映射、`image_gen` / `image_edit` 的入参形式以主 `SKILL.md` 工具协议为准。
- **每张图独立完成方案规划**；是否串联推进按主 SKILL 流程执行（默认串联推进，仅在用户要求确认或下一张强依赖上一张真实结果时停下）。
- 交付前按主 SKILL「交付齐套自查」数清交付物，按本文件「品牌应用 QA」过检查点。

## 工具与脚本

以主 `SKILL.md` 的工具协议为准。`ratio` 单独作为工具参数传入，不写进 prompt。

- **文生图 `image_gen`**：仅在没有任何用户参考图、历史生成图或品牌核心资产，且必须建立第一张主 KV 母版时使用。
- **图生图 `image_edit`**：所有需要继承品牌识别的延展、套图、物料家族内部派生，必须使用。

## 输出形式

### 尺寸与画幅默认值

`ratio` 只决定生成图片画幅；真实印刷尺寸（易拉宝 80×200cm、背板 300×400mm、门店灯箱等）必须来自用户或制作方资料，缺失时只表达比例关系，不编造精确毫米数。

| 物料 | 默认画幅 | 用法 |
|---|---|---|
| 主 KV / 主视觉母版 | 16:9 或 4:3 | 确认品牌识别母版：主标、色彩、字体、图形母题，保留延展余量。 |
| 活动海报（竖版） | 3:4 | 线下张贴、展板、社交竖版分发。 |
| 传播封面（横版） | 16:9 | 官网首屏、公众号头图、跨平台通用封面。 |
| 内容卡片 | 1:1 或 4:5 | 卡片家族、贴文配图、展板小卡。 |
| 宣传册 / 折页内页 | 3:4 或 4:3 | 多页跨页系统，单页独立生成后拼接预览。 |
| 落地页 / 长页 | 9:16 或 3:4 竖向 | 纵向分区结构；单屏独立生成后可拼接为长页预览稿。 |
| 展会背板 | 3:4 或 9:16 | 远距识别，主标题超大，副信息分级。 |
| 展会指引 / 资料袋 / 打卡装置 | 3:4 或 1:1 | 中近距，图形母题优先。 |
| 易拉宝 | 3:4 | 竖版长条感，主标题中上，CTA 中下。 |
| 门店门头 / 灯箱 | 16:9 或 21:9 | 超宽横向，品牌识别最大优先。 |
| 门店墙面 / 陈列 | 4:3 或 3:4 | 叙事与场景，商品或产品为辅。 |
| 贴纸 / 周边 | 1:1 | 小尺寸可识别，图形母题 + 极简文字。 |

### 物料版式骨架

| 物料类型 | 物理分区与结构骨架 | 结构红线 |
|---|---|---|
| 主 KV / 主视觉母版 | 主视觉主体区 / 主标语区 / 品牌落款区 / 延展留白区 | 必须留出可裁切可换比例的余量；品牌识别完整不裁切。 |
| 活动海报（竖版） | 顶部活动期次与主视觉 / 中部主标与核心信息 / 下部信息条与 CTA / 底部品牌落款 | 一张海报只承载一个核心主张；信息层级不超过 3 级；Logo 不与高对比背景直接相撞。 |
| 传播封面（横版） | 左侧主标与信息 / 右侧主视觉（或反之）/ 品牌落款 | 主标在缩略图下仍可读；不放长段正文。 |
| 内容卡片家族 | 统一栅格 + 变化的信息容器 / 统一品牌落款位 | 家族内栅格、色板、落款位一致；每张承担不同信息任务，不做同画面换角度。 |
| 宣传册 / 折页 | 封面 / 内页节奏（信息页+图页交替）/ 封底 | 跨页关系成立；内页不塞长段正文；折页需考虑折线两侧的图文关系。 |
| 落地页 / 长页 | 首屏钩子 / 逐屏信息推进 / 信任与证据 / 收口 CTA | 逐屏单一信息任务；首屏不塞全部信息；正式交付按屏独立生成，长图拼接稿须标注为预览稿。 |
| 展会背板 | 上部主标与品牌 / 中部主视觉与核心信息 / 下部信息条 | 远距可读；主标题字号占比极大；正文小字不作为远距信息载体。 |
| 展会指引 / 资料袋 / 打卡装置 | 图形母题主导 / 短信息 / 品牌识别 | 图形母题可追溯到主 KV；不引入新品牌识别。 |
| 易拉宝 | 顶部主标题 / 中部卖点与主视觉 / 下部 CTA 与落款 | 远距看主标题、近距看 CTA；三条卖点以内。 |
| 门店门头 / 灯箱 | 品牌识别居中或居左主导 / 品类副信息 | 品牌识别最大且最简；不叠加促销信息。 |
| 门店墙面 / 陈列 | 场景叙事 / 产品或商品为辅 / 品牌落款 | 场景不喧宾夺主；品牌识别完整可见。 |
| 贴纸 / 周边 | 图形母题主导 / 极简文字 / 品牌识别 | 小尺寸下品牌识别仍成立；不塞多行文字。 |

## 设计规范

### 品牌资产继承协议

- **继承优先级**：Logo 识别 > 包装识别 > IP 识别 > 主 KV 构图 > 品牌色板 > 字体气质 > 图形母题。前者与后者冲突时以前者为准。
- **只继承锚点，不继承杂物**：从核心资产只提取品牌识别要素；旧背景、旧裁切、旧道具、旧文字、偶然出现的其他品牌标识不作为锚点。
- **品牌色占比有主次**：主色主导、辅色支撑、点缀色克制。同一系列内主辅色比例保持稳定，不逐张漂移。
- **字体气质不逐张跳变**：主标字体气质在系列内统一；仅在物料尺寸差异过大时（如超宽灯箱）做等比适配。
- **多语言物料**：中英文各自按字重与字面长度重新排布，不机械拉伸同一版式；品牌识别位置保持不变。

### 平台借用规则（不重建平台调性）

命中具体平台时，本 ref 只向对应 media ref 借三样东西，其余不碰：
1. **画幅与安全区**（如公众号 2.35:1、抖音底部 20% 禁放关键信息）。
2. **信息密度与阅读场景**（如社媒封面极简、落地页逐屏推进）。
3. **该平台可用的核心资产形式**（如已有主 KV 时可直接作为平台版核心资产）。

平台的调性、钩子设计、赛道配色、平台专属特效**一律不引入**——那些属于 media ref 的职责。在本 ref 里只按通用设计语言表达气质，最终 prompt 也不出现平台名。

### 版式与信息层级

- 一张物料只承载一个核心主张；次级信息不超过 2 级。
- 品牌识别在骨架阶段定位，跨系列不漂移。
- 留白是品牌物料的资产，不是剩余空间；户外与展会物料留白比例更高。
- 长页与多页物料必须形成"疏-密-疏"的阅读节奏，不允许每页都是"图 + 三行字"。
- 文字容器样式（角标、色块、描边、底板）在同家族内统一，形成组件家族。

### 落地页 / 长页与多页物料

- 逐屏独立规划，每屏一个信息任务：首屏钩子 → 核心主张 → 场景/痛点 → 证据与细节 → 信任背书 → 收口 CTA。
- 逐屏独立生成，屏与屏之间锁定全局视觉参数（光影方向、背景材质、主色、字体气质），后一屏逐项继承前一屏已确立的参数。
- 用户要求"一张长图"时，可把已生成的单屏拼接为长页预览稿，并明确标注为预览稿而非站点直接上传素材。
- 具体屏次、证据要求与信任背书合规边界，电商场景走 `ecommerce-design.md`；本 ref 只负责品牌侧的版式与资产继承。

### 空间与户外物料

- **门店**：考虑人流方向与视线高度；门头做远距识别，墙面与陈列做中近距叙事，收银与堆头做转化承接。
- **展会**：先定展位动线再定版式；背板管远距识别，指引与资料管中距阅读，打卡装置管传播与分享。
- **易拉宝**：竖版长条版面，主标题置于中上（远距视线），CTA 置于中下（近距阅读）。
- 空间与户外物料可使用透视与场景表达（目标是空间展示时）；其余平面物料不添加无关展示背景。

### Prompt 策略

品牌应用衍生的 prompt 写清三段：
1. **参考图作用**：逐张说明 `[img0]`（主 KV / Logo / 包装，负责什么）与 `[img1]`（物料家族上一张，负责什么）的作用。品牌识别由参考图承担，文字不复述外观。
2. **目标与版式**：这张物料是什么类型、什么物理尺寸感、什么观看距离、分区怎么排、主标与品牌落款在哪。
3. **文字与落点**：逐字写出事实文案，说明落在哪个容器、什么字号层级。

风格描述使用通用视觉语言（材质、光影、色彩、版式、构图），不使用第三方品牌、受保护 IP 或在世艺术家姓名作为风格锚点。需要美学风格词时按主 SKILL 规则从风格表达角度选，不做机械标签堆砌。

### 平面物料 Prompt 模板

以下模板只用于起草方案，传入工具前必须替换成具体画面描述；不要把模板标题、字段名、说明语或未提供信息渲染进画面。

#### 主 KV / 主视觉母版

```text
生成一张品牌主视觉母版。画面包含主视觉主体区、主标语区、品牌落款区和可裁切的延展留白区。主视觉承担品牌识别与情绪表达，主标语使用已确认的品牌文案并逐字写出，品牌标识放在固定的落款位置，与背景保持足够对比。整体气质用具体的光影、材质、色彩和版式语言描述，不用空泛的形容。画面保留足够留白与色域，便于后续裁切为竖版海报、横版封面、展会背板和周边小图。
```

#### 活动海报（竖版）

```text
生成一张竖版活动海报。版面自上而下分为活动期次与主视觉区、中部主标与核心信息区、下部信息条与行动引导区、底部品牌落款区。主视觉占主要面积，主标使用已确认的活动主文案并逐字写出，核心信息不超过两级。品牌标识完整放在底部落款区，尺寸克制、不与高对比背景相撞。信息层级清晰，文字与图形不互相遮挡。
```

#### 展会背板 / 易拉宝（远距识别）

```text
生成一张展会背板（或易拉宝）画面，按远距离观看设计。主标题字号占据画面主要高度，是第一眼唯一需要读清的信息；中部为主视觉与不超过三条的核心信息；下部为行动引导与品牌落款。品牌标识与主标题保持足够对比。正文小字不作为远距信息载体，细节近看可读、远看形成清晰的块面层次。
```

#### 内容卡片家族中的一张

```text
生成一张品牌内容卡片，沿用同家族已确认的栅格、色板、文字容器样式和品牌落款位置。参考图中承担品牌识别的部分保持不变，本张只更换信息任务与配图：说明本张要讲什么、信息容器如何分布、图形与文字的体积占比。文字使用已确认内容并逐字写出。卡片不重复上一张的构图与信息。
```

#### 贴纸 / 周边

```text
生成一张品牌贴纸（或周边）平面稿，正视或正交平面，无场景。画面以可追溯到主视觉的图形母题为主体，配极简文字和品牌标识；在小尺寸下品牌识别仍然成立，不堆叠多行文字。轮廓、裁切关系和材质表现清晰。
```

## 品牌应用 QA

交付前逐项检查；不通过时先改方案或重新生成，不带着已知问题报完工。

- **品牌识别到位**：Logo / IP / 包装识别在每张物料上都完整可辨，未被裁切、变形、加描边投影或与背景相撞。
- **一致性**：全套物料的品牌层锚点（Logo 版本与位置、主辅色比例、字体气质、图形母题）稳定，未逐张漂移；物料家族内栅格与落款位一致。
- **差异真实**：不同物料之间在画幅、场景、观看距离、信息密度上有真实差异，不是同一画面换比例或换背景。
- **主 KV 先行**：超过 2 张的成套物料，第一张确实是可延展的母版，后续由它派生而非各自独立生成。
- **远距可读**：展会背板、门头、易拉宝的主标题在预期观看距离下成立；小字未被当作远距信息载体。
- **信息层级**：单物料只承载一个核心主张，层级不超过 3 级，文字与图形不互相遮挡、不裁切。
- **文字准确**：品牌名、中英文名、Slogan、活动名、日期、地点、联系方式全部来自用户提供或已确认资产，无占位符、无编造数值。
- **风格合规**：未使用第三方品牌、受保护 IP 或在世艺术家姓名作为风格锚点。
- **长页合规**：长页/多页拼接稿已标注为预览稿；正式交付按屏/按页独立生成。
- **交付齐套**：承诺的物料数量已全部产出，主 KV 与各触点物料的版本对应关系清楚。

## 参考文件

### 附表1：品牌触点物料的远距与信息密度分级

| 层级 | 典型物料 | 观看距离 | 主信息 | 正文承载 |
|---|---|---|---|---|
| 远距识别 | 门头、灯箱、展会背板、易拉宝、巨幅主 KV | 5m 以上 | 品牌识别 + 单一主张 | 不承载正文 |
| 中距阅读 | 活动海报、展板、墙面、宣传册内页、落地页 | 1–3m | 主张 + 核心信息 2–3 条 | 承载短句，不承载长段 |
| 近距细读 | 内容卡片、贴纸、周边、资料袋、桌面物料 | 0.3–1m | 具体信息 | 可承载 2–4 条短说明 |

同一套物料可以跨层级复用同一主视觉，但**版式重心必须随层级改变**——远距版放大主标、削减信息量，近距版才展开细节。直接按近距版等比缩放做远距版是最常见失败。

### 附表2：品牌资产到物料的映射检查

| 资产类型 | 必须出现在 | 常见丢失 |
|---|---|---|
| 主 Logo | 门头、背板、海报落款、卡片角标、周边 | 小尺寸物料上被省略；被压到过小不可读 |
| 品牌主色 | 全部物料 | 辅色物料上主色占比过低导致识别断裂 |
| 包装识别 | 门店、展会、电商联动物料 | 换物料时只留 Logo 不留包装结构 |
| IP 形象 | 贴纸、周边、打卡装置、活动主视觉 | 跨物料时 IP 姿态与比例漂移 |
| 字体气质 | 全部含文字的物料 | 逐张切换字体，系列感断裂 |
| 图形母题 | 周边、卡片、指引、资料袋 | 只在主 KV 出现，下游物料不延展 |

### 附表3：品牌物料合规门禁

- 通用强制：文字必须明文，不使用占位符；不使用极限词与虚假承诺；无第三方品牌、受保护 IP、在世艺术家姓名作为风格锚点。
- Logo 门禁：不变形、不拉伸、不换色、不加描边投影渐变外发光、不与杂乱背景直接相撞、不被裁切。
- 事实门禁：品牌名、Slogan、活动名、日期、地点、联系方式、版权与监管声明只能来自用户提供或已确认资产。
- 功效与对比：健康、功效、收益、环保、认证、对比类表述必须由用户提供，否则改为中性表达。
- 户外与展会：主标题远距可读；不把长段正文交给这类物料承载；不承诺未经用户确认的印刷与制作规格。

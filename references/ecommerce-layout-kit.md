# 电商成套物料 · 版式组件库（写提示词前先读这一份）

> **什么时候读**：任务涉及**电商主图 / 详情页 / 信息型卖点副图 / Banner / 参数页 / 配件清单** → 在**写提示词之前**读。
> **怎么用**：按产物类型挑 **3–8 个组件**，把每个组件「可直接抄」那一行**原样写进提示词**。
> **为什么必须这么用**（2026-10-21 实测：同一条 628 字提示词在 `gpt-image-2.5` 上重跑 vs 另一套 300 字提示词的产出）：
> ① 同一条 **628 字**提示词（明确写了指示线标注 / 四字排比 / 底部信息条 / 雾感渐变背景）→ `gpt-image-2.5` **全部画出来了**，与该产品此前的高质量成图同档；
> ② 同一天另一套约 **300 字**提示词（没写这些）→ 一个都没画，图很朴素。
> **结论：提示词里写没写 = 图上有没有。**所以这里给的不是「设计道理」，是**可以直接抄的句子**。
> **注意**：平台硬性规范（画幅比例、禁用元素）以 `ecommerce-design.md`「模块2：平台产品图规范」为准；本篇只管**怎么排版更好看**。

## 一、组件库

### A. 背景与光

| 组件 | 适用 | 可直接抄 |
|---|---|---|
| A1 雾感渐变背景 | 卖点图、详情页、场景图（**不要死白**） | 「背景为非常淡的雾蓝到暖白柔和渐变，干净无杂色，不要纯白死白；产品下方一圈极淡的柔和投影」 |
| A2 纯白无缝背景 | 平台合规首图 | 「纯白无缝背景，无渐变、无纹理、无阴影以外的任何元素」 |
| A3 暖白/浅灰渐变 + 轻投影 | 质感向主图 | 「背景为浅灰到暖白柔和渐变，底部一层极浅的投影，投影方向与左上方主光一致」 |
| A4 生活场景背景 | 场景带入图 | 「真实的午后单人小厨房桌面：浅色木纹桌面、窗边、窗外虚化绿影，暖白自然光从画面左后方斜射进来并在桌面投出柔和斜向光影」 |

### B. 标题与文案层（电商主图的高级感主要来自这一层）

| 组件 | 适用 | 可直接抄 |
|---|---|---|
| B1 巨字主标题（两行断句） | 卖点解析图、详情页首屏 | 「画面左上（或顶部横贯）一行超大中文主标题，厚重无衬线黑体、字重极粗、字色近黑，分两行断句，标题要压过画面」 |
| B2 四字排比副标题 | 卖点解析图 | 「主标题下方一行四字排比副标题（如『煮 炖 煎 蒸 涮』『快 准 省 多』），逐字加宽排列，细黑体、字色中灰」 |
| B3 底部信息条 | 规格页、详情页、需要参数兜底时 | 「画面底部一条横贯的半透明浅色信息条，条内一行小字把关键参数用间隔点串起来（如『1.5L 容量 · 适配 1-2 人 · 300W/600W 双档火力』），字色中灰、字号小但清晰可读」 |
| B4 胶囊标签 | 卖点图、场景图 | 「产品旁放 2-3 枚小白底圆角胶囊标签，内含短卖点（如『食品级不锈钢』『双层隔热』），深灰小字，标签与产品保持呼吸间距」 |
| B5 指示线 + 圆点标注 | 卖点解析图、材质页、参数页 | 「产品右侧引出 2-3 条**细指示线**，线端一枚小橙点，对应右侧短文字标签（如『上层蒸』『加厚内胆』）；指示线要细、颜色克制、不穿过产品主体」 |
| B6 参数表 | 参数/规格屏 | 「下半部分为规整参数表：表头浅灰底，两列（参数名 / 参数值），行高一致、字号统一、边界干净，不要花哨线条」 |
| B7 深浅对照版 | 同一版式出第二张 | 「与上一张同版式同构图，把背景换成深色（深蓝或近黑），产品与文字保持同样的位置与层级；深色版用橙色/金色做强调数字」 |
| B8 材质宫格 | 材质/细节屏 | 「2×2 四宫格，每格一张产品局部微距（内胆/蒸屉/盖钮/外壳），每格下方一枚深底白字小标签写材质名（如『加厚铝合金基材』『食品级不锈钢蒸屉』）」 |
| B9 破框叠层 | 详情页中段 | 「产品局部放大后破出画面边界，形成前后景层次；被裁切的部分是产品局部而不是文字」 |
| **B10 彩色功能信息卡** | 卖点解析图、详情页首屏（**信息型首选**） | 「画面左侧纵向排布 2 枚圆角矩形信息卡，每张卡顶部用一根细线悬挂于画面上边缘，卡片带白色描边与轻微投影：上面一张蓝色底、白色粗体两行字「1.5L」与「单人餐」；下面一张橙色底、白色粗体两行字「600W」与「双档火力」；两张卡大小一致、左对齐、间距均匀」 |
| **B11 对角飘带** | 卖点解析图、促销图（承载一句总卖点） | 「画面右上角一条红色对角飘带，斜向放置、末端为尖角、带轻微投影，飘带内白色小字「蒸煮涮 一锅全包」；飘带完整落在画面内，尖端不被裁切」 |

**色-语义绑定（别随机配色，2026-10-27 实证有效）**：蓝＝容量/尺寸，橙＝功率/性能，绿＝健康/安全/食品级，红＝促销/强调，灰＝中性参数。一张卡只放一个数字 + 一句释义，两行封顶。

### C. 产品呈现

| 组件 | 适用 | 可直接抄 |
|---|---|---|
| C1 视角分层 | 整套图 | 「远景/中景/近景各承担不同卖点，不要整套都用同一种正视平拍」 |
| C2 局部半透明透视示意 | 讲**工作过程**（下层煮、上层蒸） | 「产品外壳保持完整，仅**局部**处理为半透明使内部可见，边缘**柔和渐隐**自然过渡；示意区内**零玻璃反光/镜面反射**；Logo、纹路、开关、把手全部原样完整浮在示意层之上；剖面读起来是**实心材质截面**，不是玻璃窗、不是开洞」 |
| C3 剖面/爆炸图 | 讲**结构层数**（几层材质、几个部件） | 「沿结构接缝做剖切分层或爆炸图分层，**硬边禁止**——用柔和渐隐与轻微投影拉开层次；每层旁标名称」 |
| C4 配件平铺 | 配件/清单页 | 「配件在右侧按 2×2 或 3×2 平铺，主体占左 2/3；每个配件用细指示线加短标签；背景干净不抢主体」 |
| C5 精修保真 | 全部图生图 | 「删除原图的水渍、污渍、划痕与杂乱背景，保留全部识别特征（Logo 手写体、开关档位、竖纹走向、把手弧度）严格依照参考图」 |
| **C6 掀盖/开盖双层展示** | 卖点解析图、详情页卖点屏（讲「两层能同时用」、讲内部状态） | 「玻璃盖被掀起、斜置于锅体右侧上方，露出上层蒸屉内部与下层锅口：上层蒸屉里放 4 个白色小包子、2 段玉米、2 个鸡蛋；下层锅内是汤面，可见面条、青菜叶与番茄片；锅口与食物上方有淡淡上升蒸汽；上下两层关系要在同一画面里一眼读清」 |

### D. 画面纪律（写进提示词能显著减少废图）

- 「整张画面里除了产品、文字、指示线和底部横条之外**不要出现任何装饰图形、色块、花朵形状**；不要水印，不要价格数字」←（这句来自一套成熟成套物料的实拍原话，效果很好）
- 「必须原样出现的中文用引号框定完整句子」（引号框定是本 skill 的既有纪律，配合双引号框定更稳）
- **文案安静区用占比写**（官方文档口径）：别只说「上方留白」，写「顶部标题横幅占画面顶部约 18%，其下方一条约占高度 8% 的带状区保持低细节——不放产品、不放色卡、不放高对比色块，使标题落在干净底色上、不与任何图形重叠」。多出来的信息是**哪里必须安静、安静多大**，模型才停得下来。（2026-10-27 本机单变量对照：加了这段之后版式结构不变、产品占比更大、卡片与画幅边距更松）
- **每段文字只出现一次**：明写「以上每一段中文只出现一次，不重复、不镜像、不在画面其它位置再写一遍」；信息卡「一行只写一个数字加一个词，不追加第三行」。文字重复、卡内多冒一行是官方文档点名的两个高频失败。（本条属**官方文档口径**，本机两版都没复现该失败，效果尚未验证）
- **数量写死**：单体组件写「恰好一条 / 恰好一枚」（`画面上恰好有 1 条标题横幅、2 张信息卡、1 条飘带、1 条底部信息条`），重复元素的数量仍按 model 轨 9 维写。别把"数一下"交给模型。
- **正向描述为主，排除项 ≤3 条**：先正向说清目标状态（「背景是极淡的浅蓝到暖白渐变，只有一层柔光投影」），再把真正必须拦住的不超过 3 条列在最后（水印 / 价格 / 二维码 / 装饰花纹）。**负向句是兜底不是主描述**——清单越长，模型越顾此失彼。

## 二、按产物类型的**必写要素**（分级，别把每张都写成信息图）

| 产物类型 | 必写要素（少而关键） |
|---|---|
| **白底首图**（合规向） | A2 纯白背景 + C1 远景 + B1 主标题（**只要 3 项**）+ D 纪律 |
| **卖点解析图·色卡型**（信息型，**首选**） | A1 雾感渐变 + **B1 顶部横幅标题** + **B10 彩色信息卡 ×2** + **B11 对角飘带** + **C6 掀盖双层** + B3 底部参数条 + D 纪律（**7 项**） |
| **卖点解析图·指示线型**（解析型） | A1 雾感渐变 + B1 巨字标题 + B2 四字排比 + **B5 指示线标注** + C5 精修保真 + D 纪律（**6 项**） |
| **场景带入图** | A4 生活场景 + C5 精修保真 + B1 标题 + B4 胶囊标签（**4 项**） |
| **详情页·首屏** | A1 渐变 + B1 标题（巨字 **或** 顶部横幅）+（B2 排比副标 **或** B10 色卡）+ B3 底部信息条 + **C1 视角**（**5 项**） |
| **详情页·卖点/细节屏** | C6 / C2 / C3 三选一（讲**状态**用 C6 掀盖、讲**过程**用 C2 透视、讲**结构**用 C3 剖面）+（B5 指示线 **或** B10 色卡）+ B8 材质宫格（**3–4 项**） |
| **详情页·参数/规格屏** | B6 参数表 + C1 远景 + A3 浅灰背景（**3 项**） |
| **配件/清单页** | C4 平铺 + B5 指示线 + A2/A3 背景（**3 项**） |

**强度分级**：白底首图不必写满（信息越少越干净、越合规）；**卖点图与详情页才值得堆信息图层**——这正是成熟成套物料的做法（首图素、卖点图信息满、参数页规整）。

**两种版式家族，同类屏只用一种，别混用**（2026-10-27 A/B 实测）：

| 家族 | 构成 | 气质 | 适用 |
|---|---|---|---|
| **色卡型**（首选） | 顶部横幅标题 + 彩色信息卡 ×2 + 对角飘带 + 掀盖双层 + 底部参数条 | 信息密度高、卖点一眼读清、电商货架感强 | 卖点解析主图、详情页卖点屏、促销屏 |
| **指示线型** | 巨字标题 + 四字排比副标 + 指示线橙点 + 单层产品 + 底部参数条 | 更「解析/说明」、留白多、克制 | 材质解析、结构说明、参数屏 |

**同屏同时堆色卡与指示线会互相抢戏，且容易把产品挤小** → 二选一。

## 三、成套图的「视觉系统」约束（一套要像一套）

同一套图里，**这几项必须统一**，否则会漂移：

1. **背景处理方式**统一（都是雾蓝渐变 / 都是浅灰 / 都是场景）
2. **标题样式**统一（字体、字重、字号层级、位置）
3. **标注元素**统一（都用指示线+橙点、都用胶囊标签、或都用彩色信息卡+飘带，不要一张一种）
4. **配色**统一（主色 + 强调色不超过 2 个，如 浅蓝 + 橙）
5. **字体与圆角**统一
6. **先出 1 张定调 → 其余按它走**（第一张定调后，把它当参考图/风格锚点复用，别每张各写各的）

## 四、出图前自检（逐项打勾，缺项先补写再发）

- [ ] 背景处理方式写了吗？（不要死白 / 要渐变 / 要场景，三选一）
- [ ] 标题层级写了吗？（主标题 + 副标题 + 信息条，按产物类型取）
- [ ] 标注元素写了吗？（指示线+橙点 / 胶囊标签 / 参数表）
- [ ] 文案是**短句或排比**，不是长句堆字？
- [ ] 关键参数写了吗？用分隔点串起来了？
- [ ] 视角和同套其它图**不重复**？
- [ ] 不可见卖点用了**透视/剖面**手法？且边缘渐隐、识别特征不切断、零玻璃反光？
- [ ] 用了信息卡的话，**颜色与语义绑定**了吗？（蓝=容量 / 橙=功率 / 绿=健康 / 红=促销，别随机配色）
- [ ] 飘带**完整落在画面内**、尖端没被裁掉？
- [ ] 掀盖/开盖的图，**上层与下层内部都读得清**吗（不能只露上层、下层糊成一片）？
- [ ] 必须逐字出现的中文用引号框定了？
- [ ] 画幅比例对？
- [ ] 文案安静区写了**占比**吗？（哪块必须干净、干净多大）
- [ ] 每段文字写了「只出现一次」吗？单体组件写了「恰好一个」吗？
- [ ] 排除项 ≤3 条，且主描述是正向的（不是一串「不要…」）？
- [ ] 画面纪律那句（不要装饰图形/水印/价格）写了吗？

## 五、出处

- **一套成熟电商成套物料的实证版式**（10 张，1.5L 小熊电煮锅）：指示线+橙点标注、四字排比、底部信息条、材质宫格、参数表、深浅对照版、雾感渐变背景（每张原提示词 600+ 字，**要素写全才画得出来**）
- **`ecommerce-design.md`「模块2：平台产品图规范」**：平台硬性规范（画幅比例、禁用元素）——**以它为准**
- **`ecommerce-design.md` L90–99**：不可见卖点的透视示意逻辑、一屏只做一件事、排版呼吸感、选屏与叙事顺序
- **2026-10-27 A/B 实测（同模型、同参考图、同画幅 1:1，只换提示词）**：591 字旧提示词 → 出「巨字标题 + 指示线橙点」旧家族；按本库「**色卡型**」措辞写 730 字 → **复刻出「顶部横幅 + 蓝/橙色卡 + 红飘带 + 掀盖双层 + 底部参数条」的目标版式**，37.6 s 一次过（旧提示词那次前两次撞上游负载失败、共 145 s）→ 组件措辞是本库最可执行的资产
- **外部提示词方法论（2026-10-27 吸收，只取能落成一句话的部分）**：① 主流图像模型官方指南（`gpt-image` 系列文档 / Cookbook、Nano Banana 系列指南）——文字要说明**出现位置与出现次数**、明确列出必须保持不变的项、摄影语言比「8K 超清」更有效、**正向表述优于否定表述**；② 社区实战指南——**copy-safe zone 用分数写**、每张参考图只派一个用途。已落进本库 D 段与自检、`model-4.5.md` 文字纪律与参考图规则；框架名词（deliverable / preserve 之类的块标签）不搬运——本 skill 输出的是连贯中文 prompt，不写标签块。
- **未验证项**：上述四条里，「文字只出现一次」「参考图单一职责」在本机对照中**都没被触发**（两版都没出现重复文字、参考图也只有同一产品的两张）→ 属文档口径、非实测。
- **`shared-style-library.md`**：配色 / 光线 / 质感 / 版式基调的统一审美基准
- **`model-4.5.md`（详细推演轨）**：把上面这些知识**转成 prompt 表达**的地方

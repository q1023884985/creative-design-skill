# 共享风格库（跨平台通用）

> **本文件是主 SKILL 路由后按需读取的共享资源，不是独立 ref。**
> 9 个 `media-*.md` 的「美学风格扩展」已统一收敛到本文件，各 ref 只保留指针。

## 使用规则

1. **用法**：为当前画面挑选 1-3 个**与平台调性和品类相符**的词，转译成具体的画面语言（光影、材质、色彩、版式、镜头）写入 prompt。**不整段复制词库，不堆砌标签。**
2. **挑选判据**：优先解决当前画面的具体问题——画面太平就选构图法则类，质感缺失就选材质类，气质不够就选色彩或流派类。风格必须服务信息层级和阅读场景，不服务"看起来高级"。
3. **强制约束**：
   - 词库已剔除全部艺术家姓名、第三方品牌与受保护 IP，只保留通用风格语言。**不得以任何形式把姓名写回 prompt**（含"某某风格""某某式"）。
   - 词条是**风格线索不是画面事实**，必须转译为可视觉化的描述（"莫兰迪低饱和灰调"→"低饱和灰调、纯色块面、无强反光"），不把词条名直接塞进 prompt。
   - 品牌专属视觉语言（品牌色、字体气质、图形母题）由核心资产承担，**不与本词库的风格词混用**，避免品牌识别被风格词稀释。
4. **与模型轨的关系**：本词库只提供风格素材，T2I / I2I 的表达方式仍按 `model-4.5.md`（详细推演轨）或 `model-5.0-pro.md`（精简骨架轨）执行。精简骨架轨下只取 1-2 个最关键的风格锚点，不做多风格堆叠。
